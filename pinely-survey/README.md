## Что это было

Одностраничный опрос для сотрудников back-office Pinely — замер, где кто стоит с AI,
чтобы собрать программу трёх воркшопов и хакатона. Хостинг — GitHub Pages, статика,
без бэкенда. Английский + русский (переключатель EN/RU). Данные не уходят никуда
автоматически: человек жмёт «Copy my answers», строку присылает Диме в личку в Slack,
Дима разбирает её локально в `decode.html`.

Прошло **две принципиально разные версии:**

### v1 — взвешенный тест со скорингом (коммиты `0eaa502`…`9241567`)
- 6-уровневая модель зрелости (Skeptic → Transformer), скрытый скоринг по медиане,
  safety gate (провал по данным ограничивал уровень), false_confidence.
- Ветвление на 3 длины по частоте использования (отсев / короткая / полная).
- Ситуационные вопросы с приманками (варианты, которые звучат правильно и не работают).
- Экран результата: уровень, «гора» из точек с отметкой, радар по 4 осям.
- Подробное ТЗ: `Пайнли/12-ТЗ-анкета-сотрудников-v2.md`.

### v2 — простой опрос без скоринга (коммит `9fba60c`, финальный)
- **Заменил v1 целиком** по `Пайнли/15-ТЗ-переделка-опроса.md`.
- 7 вопросов на одном экране, блоки раскрываются по ответу на Q2 (частота).
- Ветки: `never` → только вопрос про доверие → «спасибо»; `rarely` → без «где
  используете» и без пункта про агентов; `regularly`/`daily` → всё.
- Никакого скоринга, уровней, радара, песочницы. В конце просто «спасибо».
- Обязательны только команда и частота, остальное можно пропустить.

## Что стоит переисповать, если будешь делать заново

Эти решения выстраданы правками по ходу — не выдумывай их снова:

- **Данные не покидают браузер.** Ноль внешних запросов (ИБ-требование Pinely было
  жёстким): весь CSS/JS внутри одного файла, favicon — inline data-URI, шрифты
  системные. Результат — base64 от JSON с префиксом, человек копирует строку руками.
  Декодер (`decode.html`) — отдельная офлайн-страница со сводкой и выгрузкой в CSV.
- **Только `sessionStorage`, в `localStorage` не писать** — меньше вопросов у ИБ и
  никакой блокировки повторного прохождения (её сознательно убрали).
- **Все видимые строки — в конфиге вверху файла**, двуязычными парами `{ e, r }`.
  Дима правит текст сам, без программиста.
- **Команды — фиксированный список без «Other»**: свободное поле даёт одну команду
  в пяти написаниях, потом чистить руками.
- **Кнопки: Back слева, Next справа** (порядок чтения).
- **Ветвление по частоте — обязательно**: непользователю нельзя задавать «где вы уже
  применяете AI», это ломает и опыт, и данные.
- Если возвращается скоринг с ветвлением — считать только по вопросам текущей ветки,
  иначе смена ответа на развилке тащит в результат данные с исчезнувших экранов.
- Стиль pinely.com: белый фон, чёрный текст, зелёный `#34A948`, кнопки-пилюли,
  зелёная точка после заголовка. Без логотипа Pinely (продукт не от их имени).
