# Опрос AI-готовности для Pinely (простая версия)

Короткий одноэкранный опрос с ветвлением по частоте использования AI. Без уровней, скоринга, радара и разбора — в конце просто «спасибо». Два файла, оба работают офлайн после загрузки.

| Файл | Что это | Кому |
|---|---|---|
| `index.html` | Опрос: 7 вопросов на одном экране, блоки раскрываются по ответу на вопрос про частоту | сотрудникам Pinely |
| `decode.html` | Декодер. Превращает строки из Slack в таблицу и CSV | только тебе |

Живые адреса:

- опрос — https://rudkovskii.github.io/pinely-survey/
- декодер — https://rudkovskii.github.io/pinely-survey/decode.html

---

## Как это работает

1. Кидаешь людям ссылку на опрос в Slack.
2. Человек отвечает в браузере. Никуда ничего не отправляется автоматически. Все ответы живут только в его вкладке.
3. В конце жмёт **Copy my answers** и присылает тебе одну строку в личку. Имя не спрашивается — личка и есть идентификация.
4. Собираешь строки, открываешь `decode.html`, вставляешь их одну под другой, жмёшь **Разобрать**. Получаешь таблицу и выгрузку в CSV.

Обязательны только два поля: команда и частота. Всё остальное можно пропустить — пустой ответ не мешает отправить.

---

## Ветвление

Ответ на второй вопрос (частота) решает, какие блоки показать:

| Ответ | Что показывается |
|---|---|
| **Никогда** | только вопрос про доверие → всё |
| **Редко** | доверие, термины, что интересно настроить, свободный текст. Без «где уже используете», в блоке интересов скрыт пункт про мини-инструменты |
| **Регулярно / Каждый день** | все вопросы |

Логика: непользователю бессмысленно показывать «где вы уже применяете AI». Если частоту пропустили — показывается полная версия (безопасный дефолт).

Тем, кто ответил «никогда», один вопрос про доверие всё же задаётся — это единственное, что осмысленно снять с непользователей. Выключается одной строкой: `SHOW_TRUST_FOR_NEVER: false` в конфиге.

## Что можно править самому

Всё в самом верху `index.html` — открой в любом текстовом редакторе, найди `const CONFIG`. Комментарии там на русском. Правило: **менять только текст внутри кавычек**, запятые и скобки не трогать.

### Язык

```js
LANG: 'en',   // 'en' | 'ru'
```

Опрос двуязычный. `LANG` задаёт язык по умолчанию; сверху страницы у человека есть переключатель EN / RU. Все строки лежат парами `{ e: 'English', r: 'Русский' }` — правишь обе.

### Команды

```js
TEAMS: [
  { id: 'finance', e: 'Finance', r: 'Финансы' },
  ...
]
```

`id` (слева) в выгрузке — менять нельзя. Добавить команду — дописать такую же строку. Свободного поля «Other» нет намеренно: иначе одна команда приедет в выгрузке в нескольких написаниях.

### Вопросы и варианты

Блок `QUESTIONS`. У каждого варианта стабильный `id` — по нему собирается выгрузка, его не трогать. Текст (`e`/`r`) правь свободно. Полезные флаги на вариантах:

- `resetsOthers: true` — «ничего из этого»: гасит остальные галочки (в терминах и в «где используют»).
- `hideInShort: true` — вариант скрыт в короткой ветке (сейчас так спрятан пункт про мини-инструменты).
- `custom: true` у вопроса — добавляет вариант «Something else» с текстовым полем; введённое уходит в выгрузку отдельным массивом (несколько пунктов — через запятую).

### Ветки

```js
BRANCHES: { never: ['q3'], rarely: ['q3','q4','q6','q7'], ... }
```

Какие вопросы показывать при каждом ответе на частоту.

## Как пользоваться декодером

1. Собери из личных сообщений все строки. Каждая начинается с `PINELY2-`.
2. Открой `decode.html`.
3. Вставь строки в поле — по одной на строку. Пустые строки и лишние пробелы декодер переживает; строку без префикса тоже разберёт.
4. Жми **Разобрать**.

Получаешь:

- плитки: сколько всего, сколько по частотам, разбивка по командам;
- таблицу по каждому человеку: команда, частота, доверие, понятные термины, где используют (+свои варианты), что интересно настроить (+свои), свободный текст;
- частотные списки внизу — понимание терминов, где уже используют, что интересно. **Это и есть материал для программы.**

Кнопка **Скачать CSV** отдаёт `pinely-survey.csv`. В Google Sheets: `Файл → Импорт → Загрузка`, разделитель определится сам. В CSV подписи уже на русском.

Декодер понимает и строки со старой (подробной) версии опроса — если такие попадутся, он покажет их отдельной таблицей «Старый формат», чтобы ничего не потерялось.

Повторное прохождение ничем не заблокировано — от одного человека может прийти две строки, бери последнюю по дате (дата есть в каждой строке и в таблице).

## Как обновить на GitHub Pages

Папка `pinely-survey/` лежит в репозитории личного сайта `rudkovskii/rudkovskii.github.io`, Pages включён. После правок:

```bash
cd ~/Documents/GitHub/"Одностраничник про меня"
git add pinely-survey
git commit -m "опрос Pinely: правки"
git push
```

Через 1–2 минуты GitHub пересоберёт сайт сам. Открой https://rudkovskii.github.io/pinely-survey/ и обнови с `Cmd+Shift+R`, иначе браузер покажет старую версию из кеша.

## Технические заметки

- Один файл на страницу, весь CSS и JS внутри. Ни сборки, ни зависимостей, ни npm.
- Ноль внешних запросов: ни CDN, ни шрифтов, ни аналитики. Требование ИБ, жёсткое.
- Прогресс — в `sessionStorage`, живёт до закрытия вкладки. В `localStorage` страница не пишет ничего.
- Строка ответов — base64 от JSON с префиксом `PINELY2-`, поле `variant: 'simple'`, `v: 4`. Если поменяешь префикс в `CONFIG.PAYLOAD_PREFIX`, поменяй его же в `decode.html` (`PREFIX`).
- Локальный предпросмотр: конфиг `pinely-survey` в `Планы/.claude/launch.json`, порт 8902.

Исходное ТЗ — `Пайнли/15-ТЗ-переделка-опроса.md`. Прежняя подробная версия описана в `12-ТЗ-анкета-сотрудников-v2.md`.
